# AI Book

منصة مدرسية تفاعلية (HTML/CSS/JS) تعمل محليًا بدون بناء (Build).

## التشغيل

```bash
cd /workspace/Ai.Book
python3 -m http.server 4173
```

ثم افتح المتصفح على:

`http://localhost:4173`

## الحسابات

- **طالب:** اسم + كلمة مرور + صف (+ ID اختياري)
- **معلم:** اسم + بريد + كلمة مرور + الرقم السري `951951`
- **إدارة مدرسية:** الاسم يجب أن يكون `ادارة المدرسة` + الرقم السري `2512011`

## الميزات

- منشورات موجّهة من المعلم حسب الصف/المادة
- منشورات عامة من الإدارة يراها الجميع
- دردشات صفية مع إضافة/إزالة أعضاء
- بحث بالحسابات عبر الاسم الرباعي أو ID
- مساعد ذكي داخل الواجهة
