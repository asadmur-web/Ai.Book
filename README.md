# Smart Sharia Education website (موقع التعليم الشرعي الذكي)

منصة مدرسية تفاعلية (HTML/CSS/JS) تعمل محليًا بدون Build.

## التشغيل

```bash
cd /workspace/Ai.Book
python3 -m http.server 4173
```

ثم افتح:

`http://localhost:4173`

## أنماط الحساب

- **طالب**
- **معلم**
- **الإدارة المدرسية**

مع وضعين:
- **تسجيل جديد**
- **مسجل دخول**

## شروط الدخول

- ID: حرفان إنجليزي كابتل + 4 أرقام (مثل `ST1234`).
- كلمة المرور: 7 خانات على الأقل وتحتوي أحرف + أرقام.
- الطالب يحتاج الرمز السري `20301`.
- المعلم يحتاج الرقم السري `951951`.
- الإدارة تحتاج الاسم `الإدارة المدرسية` + اختيار المنصب + الرقم السري `2512011`.

## الميزات الرئيسية

- منشورات موجهة من المعلم بحسب الصف/المادة.
- منشورات من الإدارة يمكن توجيهها لصف محدد أو لجميع الصفوف.
- دردشة الطاقم المدرسي (للمعلمين والإدارة).
- دردشات صفية + دردشة مباشرة تستطيع الإدارة فتحها مع أي مستخدم.
- سجل علامات كامل شبيه eSchool للفصل الأول والثاني:
  - يومي أول
  - شهرين
  - يومي ثاني
  - نهائي
  - تقويم نوعي
- حساب تلقائي للمحصلة النهائية:
  - من 100 للمواد العادية
  - من 200 لمادة **المواد الشرعية** (مضاعفة)
- بطاقات تعليمية تفاعلية للطلاب (سؤال متجدد + إظهار الإجابة).

> ملاحظة: لا يوجد مساعد ذكاء اصطناعي في الواجهة الحالية.

- يتم حفظ جلسة تسجيل الدخول محلياً، وعند إعادة فتح الصفحة يعود المستخدم مباشرة إذا كانت الجلسة صالحة.
